User experience was a priority with the inclusion of a dynamically updated map displaying the currently quried listings which can also be filtered through a price range. The website also comes with multilingual support which was also custom-made to suit the project needs.

ประสบการณ์ของผู้ใช้เป็นสิ่งสำคัญ โดยมีการเพิ่มแผนที่ที่อัปเดตแบบไดนามิกแสดงรายการที่กำลังค้นหาอยู่ในปัจจุบัน ซึ่งสามารถกรองตามช่วงราคาได้ด้วย เว็บไซต์ยังรองรับหลายภาษา ซึ่งได้รับการออกแบบเป็นพิเศษเพื่อให้เหมาะกับความต้องการของโครงการ

Global Top Group Website

เว็บไซต์ Global Top Group

 Link ลิงค์

I led the redesign and implementation of a real estate developer subsidiary Wordpress website which had a lot of issues such as poor responsive design, bloated theme and plugins setup which lead to a massive website that everything caused problems with the backup system. So I made plans to trim down the website while keeping all its content, while adding more functionality and optimization to bring it inline with modern web standards. My solution was to create a custom lightweight theme that resulted in a much faster loading speed and a cleaner architecture that cuts down on storage space, solving the storage issues.

ผมได้กำหนดทิศทางการออกเเบบเเละปรับปรุงเว็บไซต์ Wordpress ของบริษัทพัฒนาอสังหาริมทรัพย์แห่งหนึ่ง ที่เว็บมีปัญหาหลายอย่าง เช่น การออกแบบที่ไม่ตอบสนองต่ออุปกรณ์ต่างๆ ธีมเเละปลั๊กอินที่ตั้งไม่ถูกต้องจนทำให้เว็บไซต์มีขนาดใหญ่เกินจนเกิดปัญหาเวลาสำรองข้อมูล ผมจึงวางแผนที่จะลดขนาดเว็บไซต์ลงโดยยังคงเนื้อหาทั้งหมดไว้ พร้อมทั้งเพิ่มฟังก์ชันและประสิทธิภาพต่างๆเพื่อให้สอดคล้องกับมาตรฐาน เว็บปัจจุบัน โดยเเนวทางการแก้ปัญหาของผมคือการทำธีมขึ้นมาเอง ซึ่งจะทำให้เว็บมีความเร็วในการโหลดสูงขึ้นได้ โดยมีโครงสร้างที่ไม่กินที่ซึ่งแก้ปัญหาเรื่องการจัดเก็บข้อมูลได้

To achieve this, I created a custom made lightweight theme that also came with custom plugins to handle extra functionalities like multilingual support or SEO. This was achieved by combining functionalities from popular plugins like Polylang, and Yoast SEO that also paywalls their features into a baked in functionality of the website, ensuring less need for constant maintenance.

เเนวทางการทำงานของผม ผมสร้างธีมของขึ้นมาเองที่มาพร้อมกับปลั๊กอินาที่ทำขึ้นมาเพื่อรองรับฟังก์ชันเพิ่มเติม เช่น การรองรับหลายภาษาหรือ SEO ซึ่งผมรวมฟังก์ชันการทำงานจากปลั๊กอินยอดนิยม เช่น Polylang และ Yoast SEO ซึ่งมีค่าใช้จ่ายในการใช้งานฟีเจอร์ต่างๆ เข้าไว้ในฟังก์ชันการทำงานของเว็บไซต์ ทำให้ลดความจำเป็นในการ บำรุงรักษาอย่างต่อเนื่อง

The main goal of the website was to be showcase the company's real estate catalog, while giving the perception of professionalism. Many improvements have been made on each pages that lead to better user experience, such as the inclusion of a search and filter function on the homepage to help facilitate discovery of various projects based on customers preferences.

เป้าหมายหลักของเว็บไซต์คือการนำเสนอแคตตาล็อกอสังหาริมทรัพย์ของบริษัท พร้อมทั้งสร้างภาพลักษณ์ของความเป็นมืออาชีพ มีการปรับปรุงหลายอย่างในแต่ละหน้าเพื่อให้ผู้ใช้ได้รับประสบการณ์ที่ดีขึ้น เช่น การเพิ่มฟังก์ชันการค้นหาและตัวกรองในหน้าแรก เพื่อช่วยอำนวยความสะดวกในการค้นหาโครงการต่างๆ ตามความต้องการของลูกค้า

วิทยานิพนธ์ของผมว่าด้วยเรื่องการสร้างความตระหนักรู้เรื่องตาบอดสีในสังคมไทย โดยชึ้ให้เห็นความเข้าใจผิดเกี่ยวกับการรับรู้ของผู้ที่มีภาวะตาบอดสีและความยากลำบากที่มาพร้อมกับภาวะดังกล่าว

Global Top Group

Link

While working on the Global Top Group website, I was also tasked with fixing glaring issues that plagued such as slow loading speed, poor responsive UI, and a miscongifured sitemap. Fixing everything lead to a roughly 200% in traffic.

ในขณะที่ผมกำลังเเก้ไขเว็บไซต์ของ Global Top Group ผทได้แก้ไขปัญหาที่หลายอย่าง เช่น ความเร็วในการโหลดที่ช้า UI ที่ตอบสนองได้ไม่ดี และ Sitemap ที่จัดเรียงไม่ถูกต้อง การแก้ไขทุกอย่างส่งผลให้ปริมาณการเข้าชมเพิ่มขึ้นประมาณ 200%

A big contributor was a sitemap that didn't account for the multilingual structure of the website, leading to incorrect indexing by Google which affects the performance of the website. Replacing it, led to the greatest increase in views and impressions as shown in the image.

ปัจจัยสำคัญประการหนึ่งคือ Sitemap ที่ไม่ได้คำนึงถึงโครงสร้างหลายภาษาของเว็บไซต์ ซึ่งนำไปสู่การ Index ที่ไม่ถูกต้องโดย Google ซึ่งส่งผลต่อประสิทธิภาพของเว็บไซต์ การแก้ไขแผนผังเว็บไซต์ ส่งผลให้จำนวนการเข้าชมและการแสดงผลเพิ่มขึ้นอย่างมาก ดังแสดงในภาพ

I have created a custom multilingual plugin with its own SEO setting combining popular plugins on the Wordpress marketing that allowed easy linking of posts in different languages along with setting up appropriate metatags, with non of the paywall hassles that would happened if the website were to use the typical plugins.

ผมได้สร้างปลั๊กอินหลายภาษาขึ้นมาเองซึ่งมาพร้อมกับการตั้งค่า SEO ของตัวเอง โดยผสานรวมปลั๊กอินยอดนิยมบนตลาดของ WordPress ซึ่งช่วยให้สามารถเชื่อมโยงโพสต์ในภาษาต่างๆ ได้อย่างง่ายดาย พร้อมทั้งตั้งค่าเมตาแท็กที่เหมาะสม โดยไม่ต้องคำนึงถึงการจ่ายค่าปลั๊กอิน
