Aegis Property

Link

A real estate listing site where I created a custom CMS that allowed non-technical personnel to easily make changes to the listing on the website which made inputting content really fast and convenient. These listings can be accessed using the search bar that dynamically query posts.

Users experience was a priority as they get a very clear pictures of where each project is located with a dynamically updated map which can also be filtered through a price range. The website has multilingual support which was also custom-made to suit the project needs.

Global Top Group Website

Link

I took charge of the redesign and implementation of an unoptimized company's subsidiary website. It was a Wordpress website that ran on a bloated theme setup and badly configured plugins. It had poor responsiveness on many screen size, and its bloated size were causing issues during backups. My solution was to create a custom lightweight theme that resulted in a much faster loading speed and a cleaner architecture that cuts down on storage space, solving the storage issues.

The main function of the website was to be show the company's real estate catalog as they are a developer company. Many improvements have been made on each project's page that lead to better user experience which was tested extensively prior to deployment with easy navigation for quick access to important information about a project.

Project InSight

Link

A thesis project to promote colorblind awareness in Thai society. This project was focused on shining light on the prevalent misunderstanding in how color'blind' people percieve the world around them along with the difficulty that comes with it.

To achieve this. I employed an interactive website medium with challenges and little interactions to convey the message and simulate the experience of having Color Vision Deficiency better than using traditional mediums like print.

Global Top Group

Link

Before working on the website Global Top Group, it had major glaring issues such as, bloated theme leading to slow loading speed, poor responsive ui, and a miscongifured sitemap. Fixing everything lead to a roughly 200% in traffic.

A big contributor was a sitemap that didn't account for the multilingual structure of the website, leading to incorrect indexing by Google which affects the peromance of the website. By replacing it, it lead to the increase in views and impressions as shown in the image.

As the website ran on Wordpress, I was able to leverage its CMS system which was modified to fit the needs of the company. This includes a custom-made multilingual function that allows easy linking of posts in different languages that also streamlines the process of setting up appropriate metatags.
